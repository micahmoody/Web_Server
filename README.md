# HTTP Web Server Rewrite

In writing my first web server, I focused heavily on just getting it working, learning the new concepts. That was effective for a while, but I neglected a lot of other habits that would have made it more scalable and readable. I was having to restructure whole functions just to add another HTTP response code, spending a very long time looking through files to find where something was defined. This branch is a rewrite of the server with all of the same features, just structured more coherently.
